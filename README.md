# 🐱 CatLaser

Лазерная игрушка для кошки на ESP8266 (Wemos D1 mini) или ESP32 (DevKit): одна или две серво,
много режимов движения и лазера, веб-интерфейс, MQTT для умного дома, статистика.

## Профили PlatformIO

| Профиль    | Плата                 | Команда прошивки                                              |
|------------|-----------------------|---------------------------------------------------------------|
| `d1_mini`  | ESP8266, Wemos D1 mini | `pio run -e d1_mini -t upload` → `pio run -e d1_mini -t uploadfs`   |
| `esp32dev` | ESP32 DevKit          | `pio run -e esp32dev -t upload` → `pio run -e esp32dev -t uploadfs` |

Сменил профиль — собрал — залил, больше ничего менять не нужно. Второй шаг (`uploadfs`) загружает
веб-интерфейс из папки `data/`. Профиль можно переключать и в VS Code внизу окна.

## Подключение

| Что                        | ESP8266 (D1 mini) | ESP32 (DevKit) |
|----------------------------|-------------------|----------------|
| Серво горизонталь (pan)    | D4                | GPIO18         |
| Серво вертикаль (tilt)     | D5                | GPIO19         |
| Лазер (управление)         | D1                | GPIO23         |
| Питание серво              | 5V (VIN)          | 5V (VIN)       |
| Земля                      | GND, общая        | GND, общая     |

Лазер подключай через транзистор или резистор, не напрямую к пину. Пины меняются в `include/hw.h`.
Две серво лучше питать от блока 5V / 1–2 А, добавь конденсатор 470–1000 мкФ у серво.

## Структура

```
include/   заголовки (platform.h — слой совместимости ESP8266/ESP32, hw.h — пины и тайминги)
src/       код модулей: config, servo_ctl, motion, laser, stats, session, mqtt_ctl, web, main
data/      веб-интерфейс (index.html, style.css, app.js) → файловая система LittleFS
```

## Различия платформ (для справки)

- **Хранение настроек:** ESP8266 — EEPROM, ESP32 — NVS (Preferences). При смене платы настройки не переносятся.
- **ШИМ лазера:** на ESP8266 программный (делит генератор с серво, поэтому «горит/не горит» идёт обычным digitalWrite),
  на ESP32 аппаратный LEDC — серво ему не мешают, плавная яркость и пульс работают без оговорок.
- **Серво:** ESP8266 — встроенная библиотека Servo, ESP32 — ESP32Servo.
